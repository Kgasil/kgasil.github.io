    Verificação por afirmação

    Próxima ação recomendada

    Metodologia e limitações

    Concordância = afirmações iguais à referência / afirmações enviadas. Cobertura = campos de referência presentes na resposta / total de campos de referência, mesmo se divergentes. Comparação literal ignora maiúsculas e espaços repetidos, mas não converte unidades, números ou sinônimos. Campos críticos ausentes ou divergentes bloqueiam a liberação simulada; outros alertas exigem revisão. Uma resposta sem alertas não é certificação de verdade, segurança ou adequação.

    Da avaliação demonstrativa à garantia de qualidade empresarial

    Uma futura solução personalizada poderá incorporar recuperação de evidências, validação semântica, conjuntos de testes versionados, métricas por modelo e revisão humana. O laboratório público é apenas uma amostra; a viabilidade de uma implantação precisa ser avaliada.

      Metodologia e limitações

          01AI ShieldIdentificar padrões sem divulgar dadosRegex · JavaScript

          Como funciona o motor

          Uma expressão regular procura formatos conhecidos. O Shield aplica padrões à entrada e à resposta simulada, substitui trechos encontrados e atribui níveis de severidade.

          O que ele não garante

          O padrão não identifica todo dado pessoal e pode confundir textos legítimos. Mascaramento não equivale a anonimização.

const email = /\b[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}\b/gi;
const masked = text.replace(email, "[EMAIL]");
console.log(masked);

          02AI GatewayEscolher um modelo respeitando restriçõesAPIs · Routing

          Como funciona o motor

          O Gateway calcula custo estimado de cada perfil fictício, elimina opções incompatíveis com privacidade, orçamento, latência, contexto ou qualidade e ordena os elegíveis pela prioridade.

          O que ele não garante

          Os preços e notas do laboratório são hipotéticos. Um roteador real exige conectores, métricas e políticas verificadas.

          JavaScript · Exemplo reduzido
          const requests = 10000;
const inputTokens = 800, outputTokens = 200;
const inputRate = 1, outputRate = 3;
const cost = requests * (inputTokens * inputRate
  + outputTokens * outputRate) / 1e6;
console.log(cost);

          03AI AssuranceComparar afirmações com referênciasEvidence · Maps

          Como funciona o motor

          O motor lê campos estruturados e compara valores normalizados com as referências fornecidas. Campos ausentes, sem evidência ou divergentes recebem alertas; divergências ou ausências críticas bloqueiam a liberação simulada.

          O que ele não garante

          Igualdade textual não prova verdade, autenticidade da fonte ou equivalência semântica.

          const reference = new Map([["lote", "pendente"]]);

          04AI PerformanceEstimar eficiência sem confundir projeção com mediçãoMetrics · Cost

          Como funciona o motor

          O simulador usa volume, preços, tokens, cache, latência e hipóteses de qualidade para comparar estratégias. O custo é calculado, mas a qualidade é declarada pelo visitante.

          O que ele não garante

          Economia projetada não é economia medida; cache também exige isolamento, validade e controles de acesso.

          05AI SentinelEntender alertas de monitoramentoTelemetry · Percentiles

          Como funciona o motor

          O motor interpreta registros CSV fictícios, calcula taxa de erros e percentil 95 pelo método nearest rank, e identifica violações dos limites e sinais informados.

          O que ele não garante

          Poucos registros não representam toda uma operação. O motor interpreta sinais declarados, não detecta ataques diretamente.

          JavaScript · Exemplo reduzido
          const latency = [100, 200, 300, 400, 900];
const sorted = [...latency].sort((a,b) => a-b);
const p95 = sorted[Math.ceil(sorted.length * .95)-1];
console.log(p95);

          O motor escolhe controles exigidos conforme dados, operação e destino. Ações de escrita ou críticas exigem aprovação e prevenção de duplicidade; a presença declarada dos controles não comprova implementação.

              03 · Referências e limites de conformidade
              NIST AI RMF ↗
              GOVERN, MAP, MEASURE e MANAGE. As categorias deste laboratório são uma adaptação educacional.
              OWASP GenAI Security ↗
              Referência de ameaças em aplicações de IA generativa, incluindo manipulação, divulgação e autonomia.
              LGPD · Lei 13.709/2018 ↗
              Proteção de dados pessoais e medidas de segurança, especialmente art. 46. Não é análise jurídica.
              ISO/IEC 42001:2023 ↗
              Sistema de gestão de IA: políticas, objetivos e processos. Referência pública geral; não é checklist da norma.
              Mapeamento temático, não uma equivalência de cláusulas ou exigências. O resultado não determina aderência à LGPD, ISO, NIST ou OWASP.
